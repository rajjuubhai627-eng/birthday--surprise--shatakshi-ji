# Birthday Celebration Web App - Shatakshi Ji 🎂✨

An extraordinary, interactive story-based birthday web application crafted with pure HTML, CSS, JavaScript, and multimedia assets.

## 🌟 Key Features & Chapters

1. **Chapter 1: Welcome & Birthday Story Intro**
   - Elegant entrance card introducing the celebration story.
   - Interactive background celebration with floating stars and confetti particles.
   - Real Studio Happy Birthday Audio track with synchronized animated equalizer.

2. **Chapter 2: Interactive Cake Cutting & Center Pop-Pop Wish**
   - Drag or tap knife to slice the birthday cake.
   - Realistic left & right cake separation animation with dynamic pop-pop birthday wish card.

3. **Chapter 3: Car Boot Video Surprise**
   - Tap-to-reveal boot surprise with high-definition video playback.
   - Thoughtful message and celebration effects.

4. **Chapter 4: Night Sky, Star Merger, Falling Cloud & Hindi Shayari**
   - Realistic midnight sky background with crescent moon and twinkling constellations.
   - "Wish Maangiye" interactive selection & personalized input.
   - Celestial Wish Orb ascends into the cosmos and merges into a shining wishing star.
   - Sculpted cloud descends with cinematic audio chimes, displaying heartfelt Hindi poetry:
     > *Muskan ka koi mol nahi hota, 😊✨*  
     > *Kuch rishton ka tol nahi hota, ⚖️❤️*  
     > *Dost to mil jate hai har raste par, 🚶‍♂️🛣️*  
     > *Lekin har koi tumhari tarah anmol nahi hota! 💎🌟*  
     >  
     > *Rishton se badi chahat kya hogi, 💫💖*  
     > *Dosti se badi ibadat kya hogi, 🤲✨*  
     > *Jisey dost mil jaaye tum jaisa, 🫂🌸*  
     > *Usey zindagi se fir shikayat kya hogi! 😌🕊️*

5. **Chapter 5: 4-Phase Journey (13 August - 16 November)**
   - Chronological reflection of key milestones (August Spark, NotebookLM Sem Grind/Grit, Mid-Sept Care & Support, October Exam Stress-Buster & Partnership).
   - Confident, platonic, and deeply respectful tone.

6. **Chapter 6: Grand Finale & Dancing Teddy**
   - Warmest wishes, celebratory dancing teddy bear, and festive confetti explosion.

## 🚀 How to Run

Simply open `index.html` in any modern web browser:
```bash
# On Windows
start index.html
```
